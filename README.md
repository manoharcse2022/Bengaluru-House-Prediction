# 🏠 Bengaluru House Price Prediction

This project predicts Bengaluru house prices using a Machine Learning model built with Scikit-learn and deployed using Gradio on Hugging Face Spaces.

## Features

- Predicts house prices based on:
  - Location
  - Total Square Feet
  - Bathrooms
  - Bedrooms
- Interactive Gradio web interface
- Machine Learning Pipeline
- Deployed on Hugging Face Spaces

## Tech Stack

- Python
- Pandas
- Scikit-learn
- Category Encoders
- Joblib
- Gradio
